# RADIOTOMY

เว็บ Atlas กายวิภาค 3D พร้อมตัวอย่างภาพ CT, MRI และภาพตัดกายวิภาคจาก NLM Visible Human Project รวมถึงสื่ออ้างอิงเรื่อง positioning และ DXA

## รันในเครื่อง

ต้องใช้ Python 3 และติดตั้ง Pillow กับ NumPy ก่อน เพราะเซิร์ฟเวอร์ใช้แปลงภาพ 16-bit จาก NLM:

```powershell
python -m pip install Pillow numpy
python dev_server.py
```

เปิด <http://localhost:8000> ในเบราว์เซอร์ เซิร์ฟเวอร์นี้ให้บริการหน้าแอปและ route `/nlm-proxy` สำหรับดึงภาพจาก NLM; `python -m http.server` ใช้แทนไม่ได้

การ deploy บน static host อย่างเดียวจะไม่มี route `/nlm-proxy`; production host ต้องมี proxy route ที่ทำงานตามข้อจำกัด NLM เดียวกัน หรือส่วนภาพอ้างอิงจริงจะโหลดไม่ได้

ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Three.js, ฟอนต์, ภาพ NLM และโมเดลหญิงจาก HuBMAP/HRA

## โมเดลกายวิภาค

โฟลเดอร์ `models/` ถูก ignore และไม่ได้รวมไฟล์โมเดลไว้ใน GitHub:

- โมเดลชายต้องมีไฟล์ `models/body.glb` จึงจะแสดงได้ ไฟล์นี้เป็นโมเดลที่ดัดแปลงจาก BodyParts3D และรวม mesh กลีบปอดจาก Z-Anatomy; ดาวน์โหลด archive ต้นทางอย่างเดียวไม่สร้างไฟล์นี้ให้
- โมเดลหญิงโหลดจาก HuBMAP/Human Reference Atlas โดยตรงจาก CDN ตอนเลือกใช้งาน (ประมาณ 212 MB)

ดังนั้น clone ใหม่ยังเปิดหน้าแอปได้ แต่โมเดลชายจะโหลดไม่สำเร็จจนกว่าจะนำ `body.glb` ที่สร้างไว้แล้วมาวางใน `models/` ส่วนเครดิต การดัดแปลง และ license ของโมเดลกับภาพอยู่ใน [ATTRIBUTION.md](ATTRIBUTION.md)

## ขอบเขตการใช้งาน

ภาพ Visible Human ที่แอปเรียกจาก NLM เป็นภาพตัวอย่างจากร่างอาสาสมัครชายและหญิง ไม่ใช่ชุดเคสผู้ป่วยต่อเนื่องหรือข้อมูลสำหรับฝึกวินิจฉัย ส่วนภาพ positioning บางภาพมีเงื่อนไขห้ามใช้เชิงพาณิชย์ โปรดอ่าน attribution ของแต่ละไฟล์ก่อนนำไปใช้หรือเผยแพร่ต่อ

เนื้อหา positioning และ DXA เป็นสื่อการเรียนรู้เบื้องต้น ไม่ใช่คำแนะนำสำหรับการดูแลผู้ป่วย ให้ตรวจทานกับ protocol และข้อมูลจากสถาบันก่อนใช้สอนทางคลินิก
