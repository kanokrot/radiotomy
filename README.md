# RADIOTOMY

เว็บ Atlas กายวิภาค 3D พร้อมคลังตัวอย่างภาพ CT, MRI และภาพตัดกายวิภาคจาก NLM Visible Human Project

หน้า **ภาพอ้างอิงจริง** โหลด PNG ตัวอย่างจากเว็บไซต์ NLM โดยตรง ต้องเชื่อมต่ออินเทอร์เน็ต ภาพเหล่านี้เป็นภาพจากร่างกายอาสาสมัครหนึ่งรายต่อเพศ ไม่ใช่เคสผู้ป่วยหรือชุดภาพต่อเนื่องสำหรับฝึกวินิจฉัย และไฟล์ PNG ไม่เก็บ DICOM metadata หรือค่าพิกเซลดิบสำหรับ window/level และการวัด HU รายละเอียดแหล่งที่มาอยู่ใน `models/ATTRIBUTION.txt`.

โมเดลหญิงโหลดจาก HuBMAP โดยตรง (ประมาณ 202 MB) ส่วนข้อมูลโมเดลและใบอนุญาตอยู่ใน `models/ATTRIBUTION.txt`.

แถบเมนูมี Atlas, ภาพอ้างอิงจริง, แนวทางจัดท่าถ่ายภาพ และเครื่องคำนวณ T-score จาก DXA. เนื้อหา positioning และ DXA ยังเป็นสื่อการเรียนรู้เบื้องต้น ต้องตรวจทานกับ protocol และข้อมูลจากสถาบันก่อนใช้สอนทางคลินิก.

## 1. โมเดลที่รวมมา
- `models/body.glb` มาจากชุด Polygon mesh ของ BodyParts3D แบบ PART-OF Tree ที่ลด polygon 99%
  โดยคงชิ้นส่วนแยกกัน 1,256 mesh และชื่อกายวิภาคภาษาอังกฤษไว้ และเพิ่มกลีบปอด 5 ชิ้นจาก Z-Anatomy
- เครดิตและรายละเอียดใบอนุญาตอยู่ใน `models/ATTRIBUTION.txt` และแสดงที่ท้ายหน้าเว็บ
- Z-Anatomy ระบุ CC BY-SA 4.0; ชื่อ lung mesh จะเข้าเลเยอร์อวัยวะภายใน
- Header ในไฟล์ OBJ ต้นทางระบุ CC BY-SA 2.1 Japan แต่หน้า license ของ archive ปัจจุบันระบุ CC BY 4.0
  จึงเก็บข้อมูลทั้งสองเวอร์ชันไว้ใน `models/ATTRIBUTION.txt`; ตรวจเงื่อนไขก่อนเผยแพร่หรือดัดแปลงต่อ

## 2. วางไฟล์
วางเป็น `models/body.glb` (หรือแก้ path ใน `layers.json`)

## 3. รันในเครื่อง
ต้องรันผ่านเซิร์ฟเวอร์ เปิดไฟล์ตรง ๆ จะโหลดโมเดลไม่ได้
```
cd anatomy-glb
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

## 4. จัดกลุ่มเลเยอร์
- `layers.json` ใช้ regex จับชื่อ mesh (ไม่สนตัวพิมพ์) ตามลำดับ ตัวแรกที่ตรงจะชนะ
- ชิ้นที่ไม่ตรงกฎใดจะไปอยู่เลเยอร์ "อื่น ๆ" และรายชื่ออยู่ในกล่อง
  "ชิ้นส่วนที่ยังไม่จัดกลุ่ม" ทางขวา ใช้ดูชื่อจริงแล้วแก้ `match` ให้ตรง
- `"tint": true` ย้อมสีทับทั้งเลเยอร์ เพื่อให้เส้นเลือดแดง/ดำเห็นชัด (ปรับสีที่ `color`)

## 5. ใส่คำอธิบายภาษาไทย
แก้ `info.json` โดยใช้ชื่อ mesh ตัวพิมพ์เล็กเป็น key
```
"aorta": {"th": "หลอดเลือดแดงใหญ่ (Aorta)", "desc": "..."}
```

## 6. เผยแพร่
อัปโหลดทั้งโฟลเดอร์ขึ้น Vercel, Netlify หรือ GitHub Pages ได้เลย (เว็บนี้เป็นไฟล์ static)

## หมายเหตุ
- ใช้โมเดลที่ไม่ใช่ข้อมูลผู้ป่วยจริง
- ใส่ข้อความเครดิตและสัญญาอนุญาตของโมเดลไว้ในหน้าเว็บ
